# Test

A minimal SwiftUI app. Displays a globe icon and a "Hello, test!" greeting.

## Structure

| File | Purpose |
| --- | --- |
| `Test/TestApp.swift` | App entry point (`@main`), hosts `ContentView` in a `WindowGroup` |
| `Test/ContentView.swift` | Main view with the greeting UI |
| `Test/Assets.xcassets` | App icons and colors |

## Requirements

- Xcode
- Swift / SwiftUI

## Build & Run

Open `Test.xcodeproj` in Xcode, select a run destination, and press ⌘R.
